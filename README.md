# AtiNAMatiC Tone — downloads

Free downloads of **AtiNAMatiC Tone**, a guitar amp simulator and multi-effects by ATIJ STUDIO:
Neural Amp Modeler captures, a 32-slot effect grid with 40+ effects, a looper, tuner and more,
as a standalone app and as VST3, CLAP, LV2 and AU plug-ins.

**Get it from the website:** <https://atij666studio.github.io/atijstudio/plugins/atinamatic-tone/>,
or pick a file from the [latest release](../../releases/latest).

This repository only holds the installers. AtiNAMatiC Tone is freeware: free to use, no account or sign-up.

Built on Steven Atkinson's open-source [Neural Amp Modeler](https://github.com/sdatkinson/neural-amp-modeler).
